# 03 · 生产：图 → 视频 → 声音 → 分段成片

本次用的是 libtv 画布 CLI（图：Lib Image 2.5 Pro；视频：Seedance 2.5；TTS：Minimax；环境音：Seed Audio；音乐：Eleven Music / Mureka）。换平台时保留流程和闸门，替换命令。

## 镜头生产链

1. **设定图**：角色转面板、场景矩阵、群演（见 02）。
2. **首帧**：以角色 + 场景为参考图生成；**尾帧**以首帧为参考生成，保证同一镜头内人物和场景一致。
3. **视频**：首尾帧生视频（frames2video），时长整数秒；对白镜头写清台词并开同期声，其余关同期声。
4. **样片先 480p**，确认后再出高清（见 06）。
5. 每个镜头一个画布节点，命名规则固定：`帧-<镜号>-首/尾`、`镜-<镜号>`、遮挡版 `-遮挡`、同期版 `-同期`、高清版 `镜HD-<镜号>`。之后补跑、出高清全靠这套命名去找原节点。

### 首尾帧的两个坑

- **尾帧链式参考首帧**只适用于构图基本不变的镜头。推拉摇移改变构图的镜头，尾帧只参考原来的尾帧，否则构图会被拉回首帧。
- **帧节点会被多个镜头复用**（例如序章第一镜和终章某镜共用同一张榻前帧）。重出某张帧之前，先查所有引用这张帧节点的镜头，一次列全再定改哪几镜——本次修完终章才发现序章第一镜同样露嘴。

### 遮挡特写的写法

只拍双眼的极近特写和「下方 20% 留字幕区」冲突：这类特写去掉字幕区约束，裁切写死「上缘到眉、下缘到鼻梁 / 鼻尖，nose tip, mouth, chin outside the frame」，再加 `No mouth, no lips, no chin`，一次即合规。

## 声音链

- TTS：旁白、主角对白、主角心声；心声单独做更近、更轻、带轻混响的处理。
- 环境音、BGM、人物定调曲分别生成；BGM 源文件转码时去掉封面图元数据（体积大）。
- 混音：xfade 逐切点过渡 + 三总线；每镜原声音量写在镜头表里，重混时可复现。

## 分段成片

- **按交互点切段**：每个场景一段视频，选择 / QTE 之间不切片。媒体清单（如 `media.json`）每段记录 `file / duration / shots[{id,start}] / cues[{who,text,start,end}]`。
- 段尾旁白不能超出最后一镜的长度（会被截断）；需要更长就让引擎定格末帧（`holdLastFrame`）。
- 变体片：同一场景按旗标播不同版本，用 `<场景>:alt` 键；旗标插入片用 `extra:<场景>:<旗标>` 键。
- Web 版统一压缩：两遍编码，视频约 220k、AAC 80k（480p）。原片单独备份，母版另出。

## 批量生成的工程化

- 每章 / 每批一个生产脚本（镜头表 + 台词表 + 混音参数），产出写进**自己的**清单文件（`media-<批次>.json`），不碰总表。
- 脚本必须可断点续跑：已出的镜头按节点名跳过；`only <镜号>` 能单独重跑。
- 循环里调 CLI 要 `< /dev/null`，否则会吞掉 stdin。
- 等后台进程不要 `pgrep -f 脚本名`：等待循环自己的命令行也含这个串，会永远自匹配。

## 踩坑（平台相关，换平台时自查同类问题）

- 图片节点挂参考图必须声明图生图模式，否则入边校验失败。
- CLI 不走代理时可能连到另一个后端，模型目录里少一批模型，看起来像「模型下架」；配好代理环境变量即可。
- 素材合规会拦某些首尾帧：换机位出新镜号，不要硬改提示词反复撞。
- 偶发 503 / 请求失败：按退避重试，不要立刻判失败（见 06 的重试策略）。
- 「算力不足」：全部停下，等用户充值。
- 同期声镜头输入素材也可能过不了合规，退回首尾帧生视频，并按新音轨重对字幕时间。

## 每段成片的验收

1. 时长、镜头起点与清单一致。
2. 抽帧：主角不露嘴、画面无字、人物造型对得上当场阶段。
3. 字幕 cues 与剧本台词一致（不一致以成片为准回写剧本）。
