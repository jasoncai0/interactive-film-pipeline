# 04 · Web Demo：调试主战场

Web 版是整个项目的调试环境：剧本、成片、引擎改动都先在这里跑通。正式版引擎（Unity）只在定稿后打包一次。

## 引擎形态

- 单个 HTML，数据与引擎分两段：`<script>` 开头是数据表（场景、结局、死亡、尾声、人物介绍、媒体清单），`// ---- 引擎 ----` 之后是播放逻辑。正式版可以原样复用数据段。
- 媒体清单内联在源文件的标记块里（如 `/*MEDIA*/…/*END_MEDIA*/`），由合并脚本整体替换。
- 竖排浮层（`writing-mode: vertical-rl` 的人物红签）宽度等于行高：`line-height: normal` 时宽度随字体变，书法网页字体按字分片懒加载，首次登场先用后备字体撑宽再收窄，看起来「先大后小」地闪。固定 `line-height: 1`，并在开机时预热要用到的字形。
- 必须带 `<meta charset="utf-8">`：本地静态服务器不带 charset 时中文按 GBK 解析，脚本整体失效。

## 场景字段（可扩展的增补点）

| 字段 | 作用 | 典型用途 |
|---|---|---|
| `lines` / `lines: s => […]` | 台词；函数形式随状态变化 | 无片时的文字版 |
| `choices[{t, go, fx, need, lock, note, hist}]` | 选项；`need` 不满足时 `lock` 置灰并说明差什么 | 让玩家知道有第三条路 |
| `extra` | 片后叠在末帧的补句（可条件） | 不补拍就加内容 |
| `noMedia: s => …` | 条件成立时播 `<场景>:alt` 变体片 | 分支版本 |
| 旗标插入片 `extra:<场景>:<旗标>` | 旗标为真时，主片后插播 | 回响、兑现 |
| `yanyi` | 演义角标 | 标注虚构 |
| `memory` | 前世记忆 | 引导选择 |
| `qte` | 连打；`win` 可为函数 | 战斗 |
| 结局 `after` | 有结局片时卡片只写片外的后果 | 避免重复 |
| 人物 `INTRO{name,title,kind,note}` | 首次登场红签 + 图鉴 | 史实 / 虚构 / 改编角标 |

字幕 cues 除了 `{who, text}` 还有特殊类型：`type: 'card'`（结局 / 章节卡）、`type: 'inscription'`（画面里的刻字、信上的字——视频里只拍看不清的刻痕，字由引擎叠）。生产脚本引入新的 cue 类型时，先在引擎里加渲染分支，合并脚本也要跳过没有 `who` 的 cue。

外围系统（ESC 菜单、图鉴、成就、流程分支高亮、设置、选择框质感）放独立文件，引擎只留挂钩，避免和剧本修改互相冲突。

## 自动检查

- **路径检查**：遍历所有选择、QTE 胜负、死亡回溯，校验跳转目标存在、全部结局和死法可达、媒体键都存在。
  - 状态键只放影响分支的字段；闭环情报和失败次数按年份失效后不进键，否则状态数爆炸（本次达 2700 万状态，约 5 分钟）。
  - 新增用 `seen.<死亡>` 做条件的选项时，把该死亡加进状态键，否则检查会漏判不可达。
  - 多个会话同时跑会互相拖慢：**最终检查只由主会话跑一次**。
- **语法检查**：只取第一个内联 `<script>` 做 `new Function`（外部 `<script src>` 会让「取到最后一个 `</script>`」的切法报错）。
- **剧本导出**：从数据表导出逐场脚本，有成片的场景给「片里没念」的句子打 †；成片字幕另导一张表。

## 合并子会话交付

1. 备份源文件和总表。
2. 用清单 cues 同步场景台词（只改静态数组，函数式台词跳过、手动核）。
3. 已配音的叠字从 `extra` 删除。
4. 更新总表 → 重新注入源文件 → 语法检查 → 复制到发布目录 → 路径检查 → 发布。

## 发布（托管有体积上限时）

- 记录每个版本的上限（本次 256MB）；超了用「删除被替换文件」（`null`）腾空间，必要时整体降码率。
- **差量 = 总表引用的新文件 + 新资源目录（图鉴图、外围 js/css）− 被替换的旧文件**。本次漏传过一次图鉴图片，补发一版。
- 大文件分批上传（单批过大容易断）。

## 本地预览

- 本地静态服务要支持 Range 请求（206 分段）：Python 自带 `http.server` 不支持，视频拖动、跳镜会退回 0 秒。用几十行的 stdlib 小服务即可。
- **审阅调试模式**：隐藏开关（`?debug=1` 或标题页组合键，Artifact 链接可能不透传 URL 参数）；任意节点跳转（按最短路径自动推出状态）、状态面板改旗标重播、版本面板切变体 / 插入片、媒体面板按镜头 / 字幕跳时间、倍速。审阅后段剧情不用从头玩。
- 固定端口并写进文档（本次 8790）。浏览器存档按端口隔离：在别的项目页面上清存档会误伤别人的数据。
