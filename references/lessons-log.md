- 旁白过量 → 8.x 口播配比，事后重混 40 段；新项目第一镜就按配比写。
- 结局片 / 结局卡重复 → 结局 `after` 字段。
- 旗标条件写反 → 旗标按动作命名，随机走局验证。
- 剧本与成片漂移 → cues 为真源 + 导出打 †。
- 托管单版本 256MB 上限 → 删除被替换文件 + 统一降码率（220k + AAC 80k）。
- 路径检查状态爆炸（2700 万）→ 状态键只放影响分支的字段，记忆按年份失效。
- 多会话同时跑重检查 → 本机负载 60+，主会话独占最终检查。
- 子会话互派冲突任务 → 只由主会话派单。
- 测试端口撞别的项目，清掉了它的存档 → 固定端口。
- 1080p：服务端并发上限约 4；瞬时失败被误记成派生片 → 就地退避重试 + audit 撤销误判；同期镜头用 audio2video 保口型和字幕时间。
- 组装守候设了「满 N 段就停」→ 改成守到全部完成。
- 结局片主角露嘴到上架前才发现 → 每段成片验收都抽帧查主角脸。

- Unity 中途调试太贵 → 验证一次后冻结，只在最终版打包。

## 2026-11-05 晚 · 1080p 母版与露嘴修正（来自三个子会话的收件箱，17 条）

- 服务端并发上限约 4 路；降路用占位进程预锁剩余镜头，不打断在跑的。
- 节点建了但没写回 URL → 重跑原节点，不重建（否则永远撞名）。
- 「节点不存在」只认平台原文；request fail 当不存在会误判派生片。
- 同期镜头 audio2video 喂原音轨，口型与 cues 保持；合规拦截降级 frames2video 并平移字幕。
- 1080p 裁到 480p 时长、音轨取 480p 原声；重跑原混音脚本时要拦截全部写入，不止构建。
- 只改旁白不重测同期起声；镜头起点比较用容差。
- 质检只卡首尾帧构图 / 起点 / 时长，中段动作差异不返工。
- 遮挡特写去掉字幕区约束，裁切写死到鼻尖以上。
- 运镜改构图的镜头，尾帧不链首帧。
- 帧节点多镜复用：重出前查全部引用（序章第一镜与终章共用露嘴帧）。
- fix 清单在合并前要压过旧清单，否则组装器把问题镜头装回去。
- 换守候进程只杀父进程，等组装子进程跑完。
- 说明文件撞名被整份覆盖 → 分文件名、共享文件只追加。
- 派生片（白场 / 定格）缓存导致 1080p 与 480p 长短不一、起点漂移 → 派生片时长以 480p 为准，组装后扫时长差。
- 回忆插入片不走主段落表，组装入口找错 → 非常规产出单独入口，写入守卫保留。
- 升路守候按「金线全退」触发，分片陆续退出期间并发空转 → 改为「总数 < 上限就补」。
- 两个批次写过同名成片，组装器按文件名挑中旧版 → 以镜头表与总表一致者为准。
- 画面里要出现的刻字（碗底「欠一局」）→ 视频只拍看不清的刻痕，cue type=inscription 由引擎叠字；新 cue 类型先加引擎渲染，合并脚本跳过无 who 的 cue。
- 「不露嘴」口径没定清，全片质检按最严报 16 条 P0 → 开工前定口径：开口和近景必遮、中远景闭嘴可接受。
- 竖排红签首次登场「先大后小」：宽度=行高随字体变，书法字体懒加载 → line-height: 1 + 预热字形。

## 2026-11-05 夜 · 补镜 G1、质检返修 FIX-4/5（10 条）

- SSIM 先缩到 48×27 再比，0.4 为界。

- 返修叠加：新 fix 在旧 fix 之上替换；换片清高清缓存；反查脚本去 -fixN 后缀防递归；临时目录 makedirs。
- 遮脸重出：写死画外不含头脸；背影重出参考图只用于服装场景；收尾近景可定格缓推零补拍；返修前读原节点真实输入。
